Output a FIT workout schema as JSON. Return only JSON, no explanation.

SCHEMA
------
kind: "default" | "poolSwim"

default:
  { "kind":"default", "name":string, "sport":Sport, "subSport":SubSport|null, "skipLastRest":bool, "items":WorkoutItem[] }

poolSwim (pool swimming only):
  { "kind":"poolSwim", "name":string, "sport":5, "subSport":17, "skipLastRest":bool, "poolLength":float, "poolLengthUnit":DisplayMeasure, "items":WorkoutItem[] }

WORKOUT ITEMS
-------------
step:
  { "kind":"step", "durationType":WktStepDuration, "durationValue":uint|null, "targetType":WktStepTarget, "targetZone":int|null, "targetLow":uint|null, "targetHigh":uint|null, "intensity":Intensity, "name":string|null }
  - Prefer targetZone (1-7 for power, 1-5 for HR) over targetLow/targetHigh — zones scale with the user's fitness; raw values only work at current FTP/HR.
  - targetZone and targetLow/targetHigh are mutually exclusive; set the unused one to null.

swimStep (poolSwim only):
  { "kind":"swimStep", "distance":float, "swimStroke":SwimStroke, "equipment":WorkoutEquipment|null, "intensity":Intensity, "name":string|null }

repeat:
  { "kind":"repeat", "repeatCount":uint, "steps":WorkoutItem[] }

PACE & CSS
----------
For running, the user may have a "threshold pace" (seconds per km) and for swimming a "critical swim speed" (seconds per 100m).
When pace/CSS zones are available, speed targets use the user's threshold pace to define zones:
  Zone 1 (Recovery):  35-100% slower than threshold pace
  Zone 2 (Easy):      15-34% slower
  Zone 3 (Tempo):     1-14% slower
  Zone 4 (Threshold): 0-5% faster to threshold
  Zone 5 (VO2Max):    6-20% faster
For swimming the same zone model applies based on CSS (seconds per 100m).
Prefer targetZone (1-5 for pace) over raw targetLow/targetHigh for speed targets.
For pool workouts default to using distance targets over time targets ensuring their pool length is respected.

UNITS
-----
Time durationValue:      milliseconds (20min = 1200000)
Distance durationValue:  centimeters (400m = 40000, 5km = 500000)
swimStep distance:        meters
HeartRate targetLow/High: raw BPM (e.g. 135)
Power targetLow/High:     raw watts (e.g. 175)
Speed targetLow/High:     m/s (e.g. 5.556)
Cadence targetLow/High:   raw RPM

RULES
-----
- Open water swim: kind="default", sport=5, subSport=18
- Virtual/indoor cycling: sport=2, subSport=58
- Pool swim: kind="poolSwim", sport=5, subSport=17
- swimStep only valid inside poolSwim; use step for all other sports
- skipLastRest=true omits trailing rest step
